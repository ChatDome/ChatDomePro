# 长期记忆与审计规范

Pi 会话保存消息、工具结果、分支和压缩；长期记忆只保存跨会话结构化事实。不得复制完整会话、接管 Pi 压缩、把模型摘要当事实、用旧记忆跳过实时检查，或把会话写入 SQLite。

## 类型、范围和结构

| 类型 | 生效条件 |
| --- | --- |
| 使用偏好 | 使用者明确陈述；属于整个部署 |
| 环境观察 | 可信工具，且对象、范围、有效时间明确 |
| 项目决策 | 使用者决定或当前项目文件提供确定证据 |
| 已验证操作方法 | 第二次成功，或一次成功后使用者确认 |

主范围为 deployment、project、target-host。方法还绑定操作系统、软件版本、前置条件、验证次数和最近时间。

事实至少含稳定编号、类型、范围、对象、属性、结构化值、有效时间、观察时间、来源、候选 或 有效、版本约束、创建时间、更新时间和修订号。不得保存密码、私钥、令牌，只保存秘密名称或引用。

## 候选、冲突和注入

合法来源仅为使用者明确陈述、结构化工具观察、当前项目文件和已验证结果。工具结果由规则产候选；偏好和项目决策由当前 Pi 回合调用记忆工具提出。不扫描完整历史。缺来源、时间或范围时拒绝。

不同时间的状态变化不是冲突；新可信观察更新当前投影，旧修订保留。只有同范围、同对象、同属性、有效时间相同或重叠且可信证据互斥时才冲突。系统展示证据并询问使用者，不自动选边；回答形成新事实，旧事实移出 有效，历史记录全过程。

按项目、目标、对象、版本、类型和时间查询 有效 记忆。普通回答不展示来源，但内部保留来源编号；查询记忆或审计时展示。主机变更前必须读取现场状态，现场优先。

## 删除、SQLite 和输出

普通删除移出 有效 并保留历史原文。彻底清除删除范围内 有效、历史原文、来源和关联内容，只留不能逆推原值的清除事件。

只有 审批控制器可打开 SQLite。当前投影与不可变历史分离；唯一约束防重复；状态与事件同事务；业务通过存储接口访问，保留未来迁移 PostgreSQL 的可能，首版不实现 PostgreSQL。

大型输出写入 审批控制器保护目录。保存前确定性遮盖令牌、私钥、密码字段和认证头，记录规则版本。SQLite 保存路径、大小、类型、时间和校验值。完整输出三十天；到期删除并追加事件。摘要、退出状态、校验值和审计长期保存。

审计事件含顺序、前一校验值、当前校验值、类型、对象、时间、入口、脱敏载荷和模式版本。它检测损坏和普通篡改，不承诺抵抗 root 重写全部状态。

## 备份和故障

备份包含 SQLite 一致性快照、保留期输出、根用户执行器日志、配置和 Pi 会话，不含模型凭据，并保存校验值、应用版本、数据库版本和 Pi 版本。

审批控制器不可用时禁止记忆写入和主机变更。审计链损坏时允许查询和导出，禁止记忆修改和主机变更，直到恢复备份或明确建立新链。
