# 安全与执行规范

## 威胁与硬约束

首版限制模型异常、提示注入、错误参数、批准重放、重复请求、下载访问内网和组件故障。恶意可信插件、根用户攻击者、用户明确 shell、内核或 Podman 未知漏洞不在保证范围。

必须满足：

1. 模型文件和 shell 工具不得在控制节点用户空间运行。
2. Pi 不得有 sudo；Pi 与插件不得连接根用户执行器。
3. 主机变更必须由审批控制器创建不可变操作。
4. 高风险始终批准；默认关闭能力配置启用后仍批准。
5. 变更前读现场；结果未知不自动重试。
6. 容器默认无网络；未授权目录不挂载。
7. 故障不触发直接执行后备。

## Podman 和镜像

每活动任务一个 rootless Podman。禁止新增权限，裁剪能力，限制中央处理器、内存、进程、临时存储和时长。默认数值在开发主机测量后确定，界面显示生效值；提高限制需批准。

不得挂载 Pi 凭据、审批控制器数据、根用户执行器套接字、设备或根目录；不得特权容器或 主机网络。

项目 .chatdomepro/sandbox.yaml 声明镜像、摘要、可选 Containerfile、挂载和资源。工作区读写；额外目录按任务且默认只读，写入单独批准。规范路径和符号链接不得越界。

默认镜像匹配控制节点发行版、版本和架构，共享内核但用户空间独立。标签首次解析后固定摘要，变化重新批准。拉取和构建是独立批准操作；首版不按远程目标换镜像。

## 网络与用户 shell

研究使用受控网页工具。下载展示命令、镜像、目录、期限、范围后批准；只为该命令及子进程开放公网。阻止回环、链路本地、私有地址、控制节点、容器网关和声明内网；解析后检查地址以防重新绑定。结束、失败、取消或超时立即撤销，批准不得复用。

!command 与 !!command 只能由使用者输入，以 Pi 普通用户在控制节点执行，不经 根用户执行器。入口不能区分用户与模型文本时必须禁用直接 shell。

## 风险和审批

| 等级 | 行为 |
| --- | --- |
| 沙箱操作 | 对应模式自动 |
| 主机观察 | 标准和有限自主模式自动 |
| 受限主机变更 | 标准批准；有限自主在授权范围执行 |
| 高风险 | 始终逐项批准 |
| 默认关闭 | 配置启用后仍逐项批准 |

风险根据操作、目标、路径、数量、远程入口、跨文件系统和回滚能力由规则计算，模型不能覆盖。

审批必须含操作编号、适配器版本、目标、完整参数或脚本、解释器、目录、环境和秘密引用、超时、风险、前置检查、影响、回滚、创建与过期时间、规范摘要。批准默认十分钟、一次使用；配置只能缩短。字段变化必须新操作。普通对话不推断批准。

注册 /accept <operation-id> 和 /deny <operation-id>。命令只提交决定；模型输出、工具输出和历史文本不能触发。

## 根用户执行器

首版适配器覆盖 systemd、Ubuntu 与 Debian 软件包、受保护配置、重启和关机。每个适配器定义输入、风险、前置检查、执行、后置检查、成功、安全回滚和 结果未知检查。

无适配器时批准完整根用户脚本，固定脚本字节、解释器绝对路径与参数、目录、环境、标准输入、超时、输出限制和摘要。根用户执行器从 根用户控制的临时文件执行，不得批准后拼接。

操作编号全局唯一。根用户执行器启动前持久化编号和摘要；相同编号返回原状态，不同摘要拒绝。审批控制器超时只能查询。退出码零不替代状态检查。

只在逆操作明确、不覆盖外部修改且状态满足前提时自动回滚，否则询问。崩溃附近不明确标记为结果未知，先查现场。取消中止 Pi 和安全容器进程，不强杀 root 操作。重启由 根用户执行器脱离 Pi 执行，恢复后 审批控制器核对。

## 审计故障

审批和操作状态变化追加校验链事件，外部输出另存校验值。启动和导出验证。失败时保留查询、对话、研究和沙箱，禁止新主机变更，直到恢复备份或明确建立引用损坏事实的新链。
