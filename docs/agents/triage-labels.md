# Triage labels

工程技能使用五种固定角色。下表定义角色与 ChatDomePro GitHub 标签之间的映射。

| 技能角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者判断范围、优先级和后续处理方式 |
| `needs-info` | `needs-info` | 等待报告者补充需求、环境或复现信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可以由 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工决策、授权或实施 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到其中一种角色时，使用表中对应的 GitHub 标签。

如需调整标签名称，修改右侧 GitHub 标签列，保留左侧技能角色不变。
