# 产品愿景与首版范围

ChatDomePro 是特别擅长 Linux 主机运维的通用计算机智能体。它复用 Pi，增加可验证主机观察、受控特权执行、长期结构化记忆和审计。ChatDomePro 与 ChatDome 长期并行；前者面向开放任务，后者保持轻量、保守。

目标使用者是管理少量 Linux 主机的个人开发者和小团队。首版不建立账户、角色或唯一所有者；Linux 权限和远程 Pi 插件决定访问，所有获准入口拥有相同权限。

首版只运行在 Linux，支持 Ubuntu 长期支持版、Debian 稳定版、虚拟机和物理主机。优先推荐虚拟机，但不强制。

## 产品承诺

1. 处理研究、文件、代码和终端任务。
2. 自主调查并持续推进多步问题。
3. 只在缺少必要决策、授权或外部信息时询问。
4. 主机变更前读取现场状态，不以记忆替代证据。
5. 阻止模型异常、提示注入或错误计划自行取得 root。
6. 保存主机操作的提议、批准、执行和结果证据。
7. 直接复用 Pi 已有能力，不重建智能体底座。

“通用”不表示每个领域优于专用智能体；主机运维是产品专长。

## 三种模式

| 模式 | 行为 |
| --- | --- |
| 对话模式 | 回答和制定方案，不主动运行模型工具 |
| 标准智能体模式 | 自主使用任务沙箱和主机观察；主机变更逐项批准 |
| 有限自主模式 | 可执行预授权的指定服务有限操作；高风险仍逐项批准 |

模式不能降低确定性风险等级或启用默认关闭能力。

## 首版范围

- Pi 模型、认证、会话、压缩、扩展、技能和终端。
- 多会话、单活动任务、消息排队、引导和取消。
- 每任务 rootless Podman、工作区读写、额外目录授权。
- 容器默认无网络；批准后只给指定下载命令临时公网。
- systemd、软件包、受保护配置、重启和关机适配器。
- 逐项批准的一次性完整根用户脚本。
- 四类长期记忆、SQLite 控制状态、审计历史与校验链。

## 首版不做

Telegram 等平台连接器、多用户与租户、远程多主机优化、集群和合规、自研模型或会话系统、pi-chat、Gondolin、默认修改 Pi、ChatDome 数据迁移、Sentinel 早期接入、最终名称和商业设计。

## 成功判断

只比较固定版本原始 Pi 与使用同版本 ChatDomePro，使用相同模型和参数。成功率优先；共同成功时 ChatDomePro Token 目标不超过原始 Pi 的 1.5 倍。回归用于发现退化，不是发布门槛。
