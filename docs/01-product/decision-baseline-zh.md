# 确认决策基线

本文防止后续模型从早期讨论恢复已取代方向。

## Pi、访问和进程

- 嵌入固定版本 Pi 软件开发工具包，不使用 pi-chat。
- 复用模型、认证、循环、会话、压缩、引导、Token 统计、终端、扩展、技能和项目可信。
- 公开接口优先；只有具体绕过可复现且无法封闭时维护最小补丁。
- Pi 与插件作为普通用户后台进程；终端退出不结束 Pi。
- 不管理账户或所有者；访问即完整授权，所有入口权限相同。
- 任一入口可批准；批准绑定操作、内容、期限和单次使用。
- 插件是可信同进程代码，恶意插件不在首版威胁模型。
- Telegram 等平台始终由独立 Pi 插件负责。
- TypeScript 实现 Pi 集成和 审批控制器；Go 实现 根用户执行器。
- 三个身份、三个 systemd 服务、Unix 域套接字，不开放网络端口。
- 主版本不兼容拒绝，次版本能力协商。
- Go 发布 x86-64 与 Arm 64 位；Git 标签触发 GitHub Release。

## 沙箱和执行

- 模型文件与 shell 工具进入每任务 rootless Podman。
- 用户 !command 与 !!command 在控制节点以 Pi 普通用户运行。
- 工作区默认读写；额外目录默认只读，写入单独批准。
- 容器默认无网络；下载只为批准命令及子进程开放公网，阻止内网和控制节点。
- 默认镜像匹配控制节点发行版、版本和架构；项目可指定固定镜像和 Containerfile。
- 标签首次解析后固定摘要，变化需批准；首版不按远程目标换镜像。
- Podman 不可用时关闭模型 shell 和文件修改，保留对话和研究。
- 首版适配器：systemd、软件包、受保护配置、重启、关机。
- 其他特权操作批准完整脚本、解释器、目录、环境和超时。
- 风险由确定性规则决定，模型不能降低。
- 高风险始终批准；磁盘重建、批量销毁、关闭全部远程入口默认关闭。
- 批准默认十分钟、一次使用。
- 每目标主机观察和变更严格串行。
- 操作编号持久且不可复用，相同编号只查询。
- 结果未知先查现场，不自动重放。
- 重启操作脱离 Pi 生命周期，恢复后核对。

## 任务、记忆、审计

- 多会话、单活动任务；消息默认排队，可明确转为引导。
- 引导复用 Pi steer，取消复用 Pi abort。
- root 操作不因取消 Pi 被强杀。
- Pi 恢复会话；SQLite 恢复外部消息、审批、操作、记忆和审计。
- 记忆分使用偏好、环境观察、项目决策、已验证操作方法。
- 范围分部署、项目、目标主机；方法绑定系统和软件版本。
- 模型只提候选，规则验证；不扫描或复制完整历史。
- 一次成功只形成方法候选，第二次成功或使用者确认后生效。
- 不同时间观察是状态变化；同一有效时间矛盾才询问。
- 普通删除保留历史；彻底清除删除原文并留无原文事件。
- 不保存密码、私钥和令牌。
- 完整输出脱敏后保存三十天；摘要和审计长期保存。
- 审计形成校验链；损坏时禁止新主机变更。
- 备份含配置、SQLite、输出、根用户执行器记录、Pi 会话，不含模型凭据。
- 默认无遥测；更新由使用者发起，先备份 SQLite。
- 只比较原始 Pi 与 ChatDomePro；日常开发主机运行回归，批量不自动重启或破坏。

## 已取代方向

| 旧方向 | 最终方向 |
| --- | --- |
| 取代 ChatDome | 长期并行 |
| 一名所有者 | 不建账户，访问即授权 |
| pi-chat、Gondolin | Pi 软件开发工具包、Podman |
| 立即修改 Pi | 公开接口优先 |
| Python 桥接 ChatDome | TypeScript 审批控制器、Go 根用户执行器|
| 三方对照 | 只对比 Pi 与 ChatDomePro |
| 测试虚拟机快照 | 日常开发主机 |
| 核心接 Telegram | Pi 插件负责 |
| Sentinel 早期里程碑 | 先沙箱、审批、systemd、审计 |
| SQLite 保存 Pi 对话 | Pi 自己保存会话 |

## 防止语义漂移

默认镜像一致不表示复制控制节点根文件系统；项目可选镜像不表示自动适配远程目标；插件可信不表示有 root 接口；访问即授权不表示普通对话可以批准；用户直接 shell 不适用于模型工具；无发布门槛不取消回归和 Token 预算。
